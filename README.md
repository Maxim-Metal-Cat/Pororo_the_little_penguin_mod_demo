# Pororo Educational Minecraft Mod (Demo)

An interactive educational Minecraft mod prototype designed for children, built on **Fabric (Minecraft 1.20.1)**. 

## Project Overview
This prototype combines the beloved universe of *Pororo the Little Penguin* with immersive gameplay to foster learning and engagement.

## Key Features & Vision
* **Educational Worlds:** Monthly themed interactive learning worlds for children.
* **AI Assistant ("Клова"):** Embedded helper integrated to guide players through educational tasks.
* **Custom Content:** Unique items, mechanics, and an exclusive in-game cape via the proposed **Pororo+** subscription model.

## Technical Stack
* Minecraft 1.20.1
* Fabric Mod Loader
* Java 21
